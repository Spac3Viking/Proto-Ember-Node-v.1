# Field-Test Checklist — Signal Threads + Saga Smith

## Manual Cycle Test

1. Create a Signal Thread.
2. Write a Current Situation.
3. Write an Open Pressure.
4. Complete one Saga Cycle (Application → Observation → Reflection).
5. Confirm the Observation was recorded.
6. Confirm the Reflection was recorded.
7. Update Compression (what is worth carrying forward?).
8. Copy Brief.
9. Export Markdown.
10. Reopen the thread and confirm it still makes sense.

## Testing Prompts

- What felt natural?
- What felt awkward?
- What did I skip?
- What did I want to write but could not?
- Could I recreate this on paper?
- Could I hand this to another AI?
