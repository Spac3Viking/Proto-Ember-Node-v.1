# Green Fire Markdown Handoff

Green Fire Markdown Handoff is the shared `.md` format for human operators, Ember Nodes, local AI, and external/corporate AI systems.

It is designed to be:
- human-readable
- AI-readable
- durable
- easy to copy, parse, and hand off

Use this template for all handoff files:

```md
---
title:
type: research-brief | field-note | bootstrap | manual-summary | cache-readme | source-summary
source:
created:
status: unverified | reviewed | trusted | local
archetypes:
tags:
license:
---
# Summary
# Key Knowledge
# Practical Use
# Risks / Unknowns
# Suggested Cache Placement
# Sources
```
