        ⬡ Local AI Setup Guide
        
      

      

        

          No active Ember Prime was detected. Ember Node works best with a local AI model host running on your machine.
          The recommended option is Ollama — a free, local, offline-capable AI runtime.
        

        

          
What is Ollama?

          

            Ollama lets you download and run open-source AI models entirely on your own machine.
            No cloud account, no internet required after setup, no data leaves your device.
          

        

        

          
How to Install

          
    
            
  1. Visit ollama.com and download the installer for your OS.
    2. 
            
  2. Run the installer (no admin required on most systems).
    3. 
            
  3. Open a terminal and start the server:
    ollama serve
    4. 
            
  4. Pull a model to use for Ember Prime:
    ollama pull gemma3:4b
    5. 
            
  5. Return to Ember Node and click ᚹ Review Runtime Stewardship → ↺ Scan to detect it.
    6. 
          

        

        

          
Windows Quick Start

          

            After installing Ollama, you can use Awaken-Ember-Node.bat to start both
            Ollama and Ember Node together with a single double-click.
          

        

        

          Ember Node will never auto-install AI runtimes or fetch installers. All setup is manual and under your control.
